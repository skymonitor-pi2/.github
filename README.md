## Purpose

This special `.github` repository provides organization-wide defaults automatically inherited by all repositories under [`skymonitor-pi2`](https://github.com/skymonitor-pi2):

- **Organization landing page** rendered at https://github.com/skymonitor-pi2
- **Adaptive brand assets** (light and dark theme logos, dashboard preview)
- **Shared community health & governance files** (contribution guidelines, security policy, code of conduct, support guide, issue forms, and pull request template)

> This repository intentionally contains **zero source code** and no private project deliverables.
