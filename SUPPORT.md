# Support & Resources

If you need help setting up, running, or contributing to **SkyMonitor PI2**:

1. **Documentation First**:
   - Check the root `README.md` and module-level READMEs (`edge/README.md`, `server/README.md`, `frontend/README.md`, `shared/README.md`, `scripts/README.md`).
   - Run the local MkDocs Material documentation server:
     ```powershell
     .\scripts\serve_docs.ps1
     ```
   - Refer to `commande.md` for daily operating commands and troubleshooting steps.

2. **Reporting Bugs or Hardware Issues**:
   - Open an issue in the relevant repository using the structured **Bug Report** or **Hardware Issue** templates.
   - Include your environment (Raspberry Pi OS / Windows / Linux), relevant logs, and whether `EDGE_SIMULATION_MODE` was enabled.

3. **Feature Proposals & Architecture Discussions**:
   - Use the **Feature Request** issue template or start a thread in GitHub Discussions.
